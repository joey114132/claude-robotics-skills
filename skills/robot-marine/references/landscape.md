# Marine Robotics Landscape — verified snapshot
**Verified: 2026-10-02 (changed entries and link fixes; rest 2026-08-05).** Entries were confirmed against live sources on this date — re-verify anything before relying on it if this snapshot is more than ~6 months old.

## Vehicle software & autopilot stacks
- **ArduSub** — ArduPilot's open-source firmware for ROVs and AUVs; feedback stability control, depth and heading hold, autonomous navigation, flexible motor mixing for custom thruster frames, native MAVLink. Docs apply to V3.5 and up. Sub-4.7.0 was released as stable on 2026-07-22 (https://discuss.ardupilot.org/t/sub-4-7-0-released/144665) and Sub-4.7.1 on 2026-09-03 (https://discuss.ardupilot.org/t/145388). The 4.7.0 notes say many parameters were renamed and re-scaled to SI units (the upgrade handles parameters automatically, but the notes suggest keeping a backup for reference) and that boards logging to LittleFS flash lose their logs on upgrade. Sub-specific 4.7.0 changes include allowing a limit on upward throttle at the surface and a baro data timeout extended to 20 s. Status: maintained. Source: https://www.ardusub.com/
- **BlueOS** — Blue Robotics' onboard platform for ROV/USV operation, development and extension (replaced the older Companion software); companion docs cover thruster/ESC setup and current budgeting. Latest stable release 1.4.6 (published 2026-09-23); a 1.5.0 beta line exists (latest 1.5.0-beta.42, 2026-09-14). Repo last pushed 2026-10-01. Status: maintained. Source: https://github.com/bluerobotics/BlueOS
- **MOOS-IvP** — MIT's open-source C++ autonomy modules for marine vehicles, built around the interval-programming (IvP) Helm behaviour architecture; maintained by MIT LAMSS, core MOOS by the Oxford Robotics Institute. Only tagged release is v24.8.1 (published 2025-11-16); source repo `moos-ivp/moos-ivp` last pushed 2026-08-04 (https://github.com/moos-ivp/moos-ivp). Status: maintained. Source: https://oceanai.mit.edu/moos-ivp/pmwiki/pmwiki.php
- **blue** — ROS 2 platform for underwater robotics research and development. MIT license, last pushed 2026-04-06. Status: maintained (research lab). Source: https://github.com/Robotic-Decision-Making-Lab/blue
- **orca4** — reference ROS 2 AUV built on the BlueROV2, ArduSub and Navigation2; useful as a worked example of wiring Nav2 to an underwater vehicle. MIT license, last pushed 2026-06-26. Status: maintained. Source: https://github.com/clydemcqueen/orca4

## Simulation
- **Stonefish** — C++ simulation library for marine robotics: hydrodynamics computed from actual body geometry, sonar models, and rendering with wavelength-dependent light absorption and scattering. GPL-3.0, last pushed 2026-07-24. A companion `stonefish_ros2` package (GPL-3.0, last pushed 2025-12-04) provides the ROS 2 interface and loads scenarios from XML. Status: maintained. Source: https://github.com/patrykcieslak/stonefish
- **HoloOcean** — Unreal Engine based marine simulator from BYU's FRoStLab, descended from Holodeck; simulates DVL, IMU, depth sensor, optical camera and imaging/profiling/sidescan/echosounder sonar. Docs latest version v2.3.0; a separate `holoocean-ros` bridge is maintained (MIT, last pushed 2026-05-21). Status: research, actively documented. Source: https://byu-holoocean.github.io/holoocean-docs/v2.3.0/index.html
- **Gazebo underwater vehicle plugins** — buoyancy, hydrodynamics (added mass handled by the physics engine, quadratic damping via plugin coefficients), thruster force-to-RPM and LiftDrag fin plugins; the tutorial works through MBARI's LRAUV. Status: maintained. Source: https://gazebosim.org/api/sim/8/underwater_vehicles.html
- **VRX (Virtual RobotX)** — Gazebo simulation environment for unmanned surface vehicles, used by the VRX competition. Apache-2.0, last pushed 2026-08-02. Status: maintained. Source: https://github.com/osrf/vrx
- **uuv_simulator** — the original Gazebo/ROS 1 underwater simulation package and still the most-cited in papers; repository is **archived**, last pushed 2023-08-08. `osrf/lrauv` (MBARI Tethys-class AUV packages) is likewise archived, last pushed 2025-03-18. Status: archived — do not start new work here. Source: https://github.com/uuvsimulator/uuv_simulator

## Underwater navigation sensors
- **Water Linked DVL A50 / A125** — A50 (https://www.waterlinked.com/dvl-a50): 0.05–50 m altitude range, 300 or 600 m depth rating, 0.17 kg. A125 (https://www.waterlinked.com/dvl-a125): 0.05–125 m altitude range, 1,000 or 4,000 m depth rating; the comparison table on the source page gives 0.98 kg while the A125 product page lists 750 g, so check the datasheet for your variant. The comparison table itself lists only the 600 m and 4,000 m variants. A100 and A250 also listed. Water Linked has belonged to NORBIT ASA since June 2026 (https://www.waterlinked.com/about). Status: commercial. Source: https://www.waterlinked.com/dvl
- **Nortek DVL 1000 (300 m)** — 1 MHz survey-grade DVL, bottom track 0.1–75 m, long-term accuracy ±0.1% / ±0.1 cm/s on the export-controlled version (>1% on the licence-free variant), 300 m depth rating, 1.7 kg in air / 0.3 kg in water. Status: commercial. Source: https://www.nortekgroup.com/products/dvl-1000-300m
- **Sonardyne Ranger 2 / Mini-Ranger 2 / Micro-Ranger 2** — the mainstream USBL acoustic tracking families for vessel-to-vehicle positioning; the product listing does not publish range or accuracy figures, so pull the datasheet per system. Status: commercial. Source: https://www.sonardyne.com/products/

## Sonar & underwater perception
- **Blue Robotics Ping360** — 750 kHz mechanical scanning imaging sonar; 0.75–50 m range, 2° horizontal × 25° vertical beam, 300 m depth rating, USB / Ethernet (UDP) / RS485, Python, C++ and Arduino libraries. $2,750. Driven by the open-source Ping Viewer application (GPL-3.0, last pushed 2025-08-07, https://github.com/bluerobotics/ping-viewer), which is also the reference implementation of the protocol. Status: commercial. Source: https://bluerobotics.com/store/sonars/imaging-sonars/ping360-sonar-r1-rp/
- **Cerulean Omniscan 450 SS** — 450 kHz side-scan sonar with separate transducer and PCBA, 0.5° beam, 150 m range, 300 m depth rating, 100BaseT Ethernet, georeferenced mosaic via SonarView. $2,590. Status: commercial. Source: https://ceruleansonar.com/products/omniscan-450-ss

## Vehicle platforms
- **BlueROV2 (Blue Robotics)** — the default open research/inspection ROV. Six T200 thrusters in a vectored layout, expandable to eight (Heavy configuration) for full 6-DOF; 100 m acrylic or 300 m aluminium enclosures; Navigator flight controller running BlueOS + ArduSub; 25–300 m tether options; ~2 h runtime (normal use) or ~4 h (light use), quoted for the 15.6 Ah pack in the spec table (the recommended pack is 14.8 V 18 Ah). From $4,900. Status: commercial. Source: https://bluerobotics.com/store/rov/bluerov2/
- **VideoRay Mission Specialist Defender** — seven-thruster modular intervention ROV aimed at heavy payloads and UXO/net work; supports third-party control and navigation software from Greensea Systems or SeeByte. Status: commercial. Source: https://videoray.com/products/mission-specialist-defender/
- **Maritime Robotics Otter (USV)** — 2000 × 1080 × 1065 mm, 62 kg dry weight, 30 kg payload, twin electric thrusters, up to 20 hours at 2 knots; Vehicle Control Station autonomy with waypoint navigation and heading control. Status: commercial. Source: https://www.maritimerobotics.com/otter

Depth ratings are not published on the overview page — request per model. Status: commercial. Source: https://www.deepinfar.com/en
- **QYSEA FIFISH** — founded 2016; claims 240+ patent applications filed worldwide and 120+ granted. V-series sport ROVs (V-EVO, V6 EXPERT, V6 PLUS at 150 m), E-series industrial (E-MASTER, E-GO), W6 NAVI maritime and X1 mission ROVs. Lineup spans roughly 100–500 m depth, with X-series customisable for 350–500 m. Status: commercial. Source: https://www.qysea.com/

Product lines: marine survey (L42, L25, M40P, V180, V20), inland survey (SL20, SL40, ME120), water rescue (Dolphin 3), firefighting (Fire Conqueror), maritime security (M75, L30). Status: commercial. Source: https://www.oceanalpha.com/

## Enclosures, sealing & tether
- **Blue Robotics watertight enclosure assembly guide** — three-O-ring flange seal lubricated with silicone grease (Molykote 111); explicitly names dust or hair on a seal face, scrapes from hard tools in the O-ring groove, over-tightened screws, and threadlocker attacking polycarbonate domes as leak causes. Status: maintained (vendor documentation). Source: https://bluerobotics.com/learn/watertight-enclosure-assembly/
- **Fathom-X tether interface board** — HomePlug AV Ethernet over a single twisted pair; 200 Mbps physical layer, ~80 Mbps practical, published maximum 2,000 m but tested to 300 m. $140 single / $280 pair. Status: commercial. Source: https://bluerobotics.com/store/comm-control-power/tether-interface/fathom-x-tether-interface-board-set/
- **BlueOS thruster & ESC integration** — recommends T200/T500 brushless thrusters, requires all motion-control thrusters on one vehicle to share the same control signal type with an ESC matched to the motor, and warns to size total current draw against the vehicle power supply. Status: maintained (vendor documentation). Source: https://blueos.cloud/docs/stable/integrations/hardware/required/thrusters/

## Research
- **AQUA-SLAM** — tightly-coupled acoustic-visual-inertial SLAM fusing DVL, stereo camera and IMU in a factor graph, with fast online extrinsic and DVL transducer misalignment calibration; validated in a tank and offshore in the North Sea. Status: research. arXiv:2503.11420. Source: https://arxiv.org/abs/2503.11420
- **RUSSO** — underwater SLAM fusing stereo camera, IMU and imaging sonar that degrades to a 3-DoF sonar-inertial system when vision fails, plus a sonar-based initialisation for feature-poor water. Status: research. arXiv:2503.01434. Source: https://arxiv.org/abs/2503.01434
- **Underwater Dense Mapping with the First Compact 3D Sonar** — first study of compact 3D sonar for underwater state estimation and mapping, with sonar-camera extrinsic calibration and acoustic-response characterisation across materials; deployed in underwater caves. Status: research. arXiv:2510.18991. Source: https://arxiv.org/abs/2510.18991
- **Sonar-based Deep Learning in Underwater Robotics: Overview, Robustness and Challenges** — survey of sonar classification, detection, segmentation and SLAM models plus datasets, simulators and robustness methods; argues the field lacks a baseline sonar dataset and has a large sim-to-real gap. Status: research (survey). arXiv:2412.11840. Source: https://arxiv.org/abs/2412.11840
- **Efficient Control Allocation and 3D Trajectory Tracking of a Bio-inspired AUV** — analytic control allocation letting a 4-actuator underactuated AUV move in up to 5 DOF in pool trials, at ~0.007 ms versus 22.28 ms for the compared optimisation-based allocator. Status: research. arXiv:2504.19049. Source: https://arxiv.org/abs/2504.19049
- **Tether-Aware Dynamic Collision Avoidance for USV-HROV Systems** — collision avoidance for a surface vessel tracking a tethered underwater vehicle that reasons about tether scraping and tautness, without an explicit tether shape model. Status: research. arXiv:2606.01112. Source: https://arxiv.org/abs/2606.01112
- **Onboard Vision and MPC Navigation for Underwater Robots: An Open BlueROV2 Platform for Multi-Robot Experiments & Docking** — BlueROV2 with a Jetson Orin NX and RealSense D435i stereo camera in a modular pressure housing, running onboard vision plus six-DOF nonlinear MPC for autonomous navigation and docking, with a quaternion-based estimator; provides open-source PX4 SITL and Gazebo simulation environments and a low-cost physical docking station. Submitted 2026-09-29. Status: research. arXiv:2609.38511. Source: https://arxiv.org/abs/2609.38511
- **A Unified Neural-Aided Alignment and Calibration Method for AUVs** — fully neural DVL initialisation pipeline for INS-DVL fusion: ResAlignNet estimates the INS-to-DVL rotation (alignment) and DCNet estimates the DVL error terms (calibration), replacing the model-based stages, in situ on a single nearly constant-velocity trajectory with the same inputs as the baseline. On real-world data across five distinct sensor error-term combinations it reduces velocity root mean squared error by an average of 68.7% over the model-based baseline using 25 s of initialisation data; the baseline needs complex vehicle maneuvers and surface-level satellite reference measurements. Status: research. arXiv:2608.22496. Source: https://arxiv.org/abs/2608.22496
- **Equivariant Filter Design for Acoustic and Depth Aided Inertial Navigation Systems** — equivariant filter (EqF) using Tangent-Group symmetry that carries IMU biases inside the state geometry, for AUV navigation with DVL velocity and pressure depth; in Monte Carlo simulation it reduces attitude, velocity and position error by 18-25% against a Two-Frame-Group IEKF and a Multiplicative EKF, and offline analysis of AUV field data corroborates this with reduced position drift. Status: research. arXiv:2609.19742. Source: https://arxiv.org/abs/2609.19742
- **Beyond Shallow-Water Photorealism: Physically and Sensor-Grounded Simulation for Deep-Sea Robotics** — extends the Stonefish simulator with stochastic IMU and DVL drift, magnetometer disturbances, higher-order hydrodynamics, terramechanics, pressure-driven environmental variability and physically based underwater optics, and the authors describe it as compatible with real-time simulation. The abstract does not say whether the extension is released. Status: research. arXiv:2608.26888. Source: https://arxiv.org/abs/2608.26888

# Aerial Robotics (UAV/Drone) Landscape — verified snapshot
**Verified: 2026-08-05.** Entries were confirmed against live sources on this date — re-verify anything before relying on it if this snapshot is more than ~6 months old.

## Autopilot firmware & ground control
- **PX4 Autopilot** — open-source flight stack for multirotor, fixed-wing, VTOL and rover; v1.17.0 is the current stable release (2026-05-13), v1.18.0-beta1 in flight test. Status: maintained. Source: https://github.com/PX4/PX4-Autopilot/releases
- **ArduPilot** — open-source autopilot covering Copter, Plane/VTOL, Rover and boats; 4.7.0 released as stable across all vehicle types on 2026-07-21 (previous stable 4.6.3, 2025-11-04). Status: maintained. Source: https://github.com/ArduPilot/ardupilot/releases
- **QGroundControl** — cross-platform ground station and mission planner for any MAVLink vehicle; supports PX4 and ArduPilot on Windows, macOS, Linux, iOS and Android; stable line v5.0. Status: maintained. Source: https://qgroundcontrol.com/

## Flight controller & companion compute
- **Pixhawk Reference Standards** — open hardware specs (autopilot FMU versions and the Pixhawk Connector Standard) governed via a SIG under Dronecode; current autopilot standards include Pixhawk v6X, v6C, v6U and v5X. Status: maintained. Source: https://pixhawk.org/standards/
- **Holybro flight controllers** — commercial Pixhawk-standard boards including Pixhawk 6X / 6X Pro / 6X-RT, 6C and 6C Mini, Pix32 v6, Durandal, plus the Kakute F4/H7 line for FPV. Status: commercial. Source: https://holybro.com/collections/autopilot-flight-controllers
- **CUAV** — Chinese (Guangdong; ICP 粤ICP备19057835号) manufacturer of flight controllers (X7+ Pro, X25 MEGA/EVO, 7-Nano v2, Pixhawk V6X v2), NEO-series GNSS, C-RTK RTK modules, P8/P9 telemetry, airspeed sensors and CAN power modules. Status: commercial. Source: https://www.cuav.net/en/
- **ModalAI VOXL 2** — 16 g companion computer with integrated flight controller on Qualcomm QRB5165 / Flight RB5 (~15 TOPS); runs PX4 as a Linux service via the `voxl-px4` package; marketed as a Blue UAS Framework AI autopilot. Status: commercial. Source: https://www.modalai.com/pages/voxl-2
- **Auterion Skynode X / AuterionOS** — commercial integrated compute-plus-autopilot module and onboard OS built on the PX4/MAVLink open standards; also sells Auterion Mission Control and a fleet/analytics cloud suite. Status: commercial. Source: https://auterion.com/

## Offboard control & middleware
- **MAVSDK** — high-level MAVLink API library with a C++ core and gRPC-served bindings for Python, Swift, Java, Go, JavaScript, Rust and C#; sync and async call styles; runs on Linux, macOS, Windows, iOS, Android. Status: maintained. Source: https://github.com/mavlink/MAVSDK
- **MAVROS** — MAVLink-to-ROS bridge and GCS proxy; ROS 2 only since 2.6.0 (2023-09-09, Humble and newer), CI across Humble, Jazzy, Kilted and Rolling; ROS 1 support ended years earlier. Status: maintained. Source: https://github.com/mavlink/mavros
- **PX4 ROS 2 Control Interface (px4_ros2)** — C++ library with Python bindings for writing custom PX4 flight modes that run on a companion computer over uXRCE-DDS and appear as native modes in the GCS, with mode executors and automatic fallback; core registration is CI-tested but several setpoint types and the API surface are explicitly experimental. Status: maintained (partly experimental). Source: https://docs.px4.io/main/en/ros2/px4_ros2_control_interface.html
- **DJI Payload SDK (PSDK)** — MIT-licensed SDK for building payloads on DJI aircraft (Matrice 300/300 RTK, Matrice 400, M4T/4E) and the Manifold 3 onboard computer; Linux and RTOS targets; current release 3.16.0. Status: commercial (vendor-maintained). Source: https://github.com/dji-sdk/Payload-SDK

## Simulation
- **Pegasus Simulator** — NVIDIA Omniverse/Isaac Sim framework for multirotor dynamics with autopilot-in-the-loop (PX4 1.14.3, ArduPilot Copter 4.4.0) and a Python control API; v5.1.0 targets Isaac Sim 5.1.0 (2025-10-26); multirotor only for now. Status: research (actively maintained). Source: https://github.com/PegasusSimulator/PegasusSimulator
- **Aerial Gym Simulator** — Isaac Gym-based MAV simulator from NTNU's Autonomous Robots Lab; GPU ray-casting for depth/segmentation, parallelized geometric controllers over thousands of vehicles, state-based policies trainable in under a minute. Status: research. Source: https://github.com/ntnu-arl/aerial_gym_simulator
- **gym-pybullet-drones** — PyBullet Gymnasium environments for single- and multi-agent quadrotor RL, compatible with stable-baselines3 2.0 and Betaflight/Crazyflie firmware SITL; MIT-licensed, maintained by UTIAS Learning Systems and Robotics Lab. Status: maintained. Source: https://github.com/utiasDSL/gym-pybullet-drones
- **XTDrone** — customizable multi-rotor/fixed-wing/compound-wing UAV simulation platform on PX4 + ROS + Gazebo for SLAM, motion planning, formation control and precision landing; created at Peking University, with a ROS 2 version (XTDrone2) released. Status: research (maintained). Source: https://github.com/robin-shaun/XTDrone

## GPS-denied estimation & onboard planning
- **OpenVINS** — MSCKF-based visual-inertial estimator from the University of Delaware RPNG; multi-camera, online calibration, ROS 1 and ROS 2 CI; won the IROS 2019 FPV Drone Racing VIO competition; latest tagged release v2.7 (May 2023) with continued repo activity. Status: research (maintained). Source: https://github.com/rpng/open_vins
- **VINS-Fusion** — optimization-based multi-sensor state estimator from HKUST Aerial Robotics (mono+IMU, stereo, stereo+IMU, with GPS fusion), GPLv3; widely used on drones but development is slow and issue backlog is large. Status: research. Source: https://github.com/HKUST-Aerial-Robotics/VINS-Fusion
- **FAST-LIVO2** — LiDAR-inertial-visual fusion localization and mapping from HKU-MARS lab, code released 2025-01-23 under GPLv2 (commercial use requires separate licensing); demonstrated on a synchronized handheld sensor rig with onboard localization in mind. Status: research. Source: https://github.com/hku-mars/FAST-LIVO2
- **EGO-Planner / EGO-Swarm** — ESDF-free gradient-based local planner for quadrotors from ZJU FAST Lab, planning in roughly 1 ms, validated with RealSense depth input; authors now point new users at EGO-Swarm as the more robust successor; GPL-3.0. Status: research. Source: https://github.com/ZJU-FAST-Lab/ego-planner

## Airframes, kits & sizing tools
- **Crazyflie 2.1 Brushless (Bitcraze)** — open-source palm-sized research quadrotor, 34 g with legs / 37 g with guards, 40 g maximum recommended payload, ~10 min flight time, long-range radio and BLE, ROS integration; aimed at education, research and swarming. Status: commercial (open hardware). Source: https://www.bitcraze.io/products/crazyflie-2-1-brushless/
- **Prometheus (Amovlab / 阿木实验室)** — Chinese open-source autonomous-drone software stack on PX4 + ROS covering control, planning, object detection and simulation, sold alongside the Prometheus 450 hardware platform with training and after-sales support. Status: maintained (vendor-backed open source). Source: https://github.com/amov-lab/Prometheus
- **eCalc / xcopterCalc** — web-based electric drive simulator for RC and UAV propulsion sizing (motor/ESC/prop/battery combinations) with a large component database; freemium — restricted demo free, full database behind membership. Status: commercial. Source: https://www.ecalc.ch/

## Regulation & airspace
- **FAA Remote ID (14 CFR Part 89, US)** — final rule "Remote Identification of Unmanned Aircraft" published 2021-01-15, requiring remote identification of unmanned aircraft to address safety, security and law-enforcement concerns. Status: in force. Source: https://www.federalregister.gov/documents/2021/01/15/2020-28948/remote-identification-of-unmanned-aircraft
- **FAA Part 108 BVLOS (US) — still proposed** — NPRM "Normalizing Unmanned Aircraft Systems Beyond Visual Line of Sight Operations" published 2025-08-07 (FR 2025-14992, touching 14 CFR 107/108/89/91); extension denied 2025-09-29, comment period reopened 2026-01-28 and closed 2026-02-11 (FR 2026-01644), a further reopening/denial notice followed 2026-02-10. No final rule as of this snapshot. Status: proposed rule. Source: https://www.federalregister.gov/documents/2025/08/07/2025-14992/normalizing-unmanned-aircraft-systems-beyond-visual-line-of-sight-operations (browser link; verify programmatically via https://www.federalregister.gov/api/v1/documents/2025-14992.json)
- **EASA civil drone framework (EU)** — three risk-tiered operational categories (Open / Specific / Certified) under Regulations (EU) 2019/945 and 2019/947 (amended by 2023/203); the Specific category uses SORA for custom risk assessment; over 1.6 million registered operators. Status: in force. Source: https://www.easa.europa.eu/en/domains/civil-drones
- **China — 无人驾驶航空器飞行管理暂行条例 (Interim Regulations on UAS Flight Management)** — State Council / CMC regulation effective 2024-01-01; real-name registration for civil UAS owners, five weight classes (micro <0.25 kg, light ≤7 kg, small ≤25 kg, medium ≤150 kg, large >150 kg), pilot certificates required for small/medium/large, and ATC approval required before flying in controlled airspace. Status: in force. Source: https://www.gov.cn/zhengce/content/202306/content_6888799.htm

## Research
- **Vision-only UAV State Estimation for Fast Flights Without External Localization** — fuses VIO, onboard landmark measurements and IMU with an explicit VIO drift model correcting position, orientation and both velocities; A2RL Drone Racing 2025 finalist (top 4 of 210 teams). Status: research. arXiv:2602.01860. Source: https://arxiv.org/abs/2602.01860
- **Kilometer-Scale GNSS-Denied UAV Navigation via Heightmap Gradients** — SPRIN-D challenge-winning onboard system for 9 km waypoint flight below 25 m AGL without GNSS, matching LiDAR-derived local heightmaps to prior geo-data via gradient-template matching in a clustered particle filter, real time on CPU-only hardware. Status: research. arXiv:2510.01348. Source: https://arxiv.org/abs/2510.01348
- **Demonstrating Agile Flight from Pixels without State Estimation** — UZH RPG vision-based quadrotor flying gate sequences at up to 40 km/h and 2 g using collective thrust and body rates, with RL-trained policies and gate-edge sensor abstraction instead of explicit state estimation. Status: research. arXiv:2406.12505. Source: https://arxiv.org/abs/2406.12505
- **Robust Visual SLAM for UAV Navigation in GPS-Denied and Degraded Environments** — comparative evaluation of ORB-SLAM3, DPVO, DROID-SLAM, DUSt3R and MASt3R under low light, haze, motion blur and combined degradation, with NVIDIA Jetson deployment analysis for SWaP-constrained UAVs. Status: research. arXiv:2605.03678. Source: https://arxiv.org/abs/2605.03678
- **Curriculum Reinforcement Learning for Quadrotor Racing with Random Obstacles** — SJTU vision-based curriculum RL with domain randomization and multi-scene updating for end-to-end high-speed flight through obstacle-rich racetracks, validated in hardware-in-the-loop and real flight. Status: research. arXiv:2602.24030. Source: https://arxiv.org/abs/2602.24030

# Legged Robotics Landscape — verified snapshot
**Verified: 2026-10-02 (changed entries and link fixes; rest 2026-08-05).** Entries were confirmed against live sources on this date — re-verify anything before relying on it if this snapshot is more than ~6 months old.

## Locomotion control frameworks (MPC / WBC / classic balance)
- **OCS2** — C++ toolbox for optimal control of switched systems (SLQ and multiple-shooting SQP solvers); the base of ETH RSL's MPC + whole-body-control stack for ANYmal and other legged robots. Status: maintained. Source: https://github.com/leggedrobotics/ocs2
- **Crocoddyl** — DDP-family optimal control library for multi-contact trajectory optimization, built on Pinocchio; widely used for legged/humanoid whole-body MPC research. Status: maintained. Source: https://github.com/loco-3d/crocoddyl
- **Pinocchio** — fast rigid-body dynamics library (forward/inverse dynamics + analytical derivatives) underlying most modern legged and humanoid WBC stacks, including Crocoddyl. Status: maintained. Source: https://github.com/stack-of-tasks/pinocchio
- **DIAL-MPC** — sampling-based (MPPI + diffusion-style annealing) full-order, torque-level MPC for legged robots; training-free, no reduced-order model needed; ICRA 2025 best-paper finalist. Status: research (open-source code). Source: https://arxiv.org/abs/2409.15610 (code: https://github.com/LeCAR-Lab/dial-mpc)
- **Capture point / ZMP balance control** — the classic reduced-order balance criteria: zero-moment-point + support-polygon reasoning for slow flat-ground walking, capture point (extrapolated center of mass) for push recovery and step timing. Still used as the deployable-observation basis in 2026 RL balance research. Status: research/classic. Source: https://www.mdpi.com/1424-8220/19/15/3407 ; https://arxiv.org/abs/2608.00500

## RL locomotion toolkits & sim environments
- **Isaac Lab** — NVIDIA's unified, GPU-accelerated robot-learning framework; successor to Isaac Gym with 30+ ready-to-train legged environments (quadruped and humanoid). Isaac Lab 3.0 Early Access (v3.0.0-EA, 2026-09-16, built for Isaac Sim 6.1 and Newton 1.5.2) adds one task API over multiple physics backends (Isaac Sim PhysX, OVPhysX, Newton/MuJoCo Warp), kit-less runs without Isaac Sim, a unified `isaaclab` train/play CLI, and changes every quaternion API from (w,x,y,z) to (x,y,z,w); General Availability is targeted toward the end of October 2026. Status: maintained (latest 2.x release v2.3.2, 2026-02-02; 3.0 in early access, checked 2026-10-02). Source: https://github.com/isaac-sim/IsaacLab ; release: https://github.com/isaac-sim/IsaacLab/releases/tag/v3.0.0-EA
- **Isaac Gym / IsaacGymEnvs** — NVIDIA's original GPU-parallel physics + RL environment suite; NVIDIA now directs users to Isaac Lab. Status: legacy (repo archived, read-only since 2026-04-14; last push 2024-10-26). Source: https://github.com/isaac-sim/IsaacGymEnvs
- **legged_gym** — ETH RSL's Isaac Gym-based quadruped/humanoid RL training environment; companion code to "Learning to Walk in Minutes Using Massively Parallel Deep Reinforcement Learning" (Rudin et al., trains ANYmal flat-terrain policies in under 4 minutes on one GPU). Status: legacy (maintainer migrated the environments to Isaac Lab and says the repo will receive limited updates and support; last push 2025-05-29). Source: https://github.com/leggedrobotics/legged_gym ; paper: https://arxiv.org/abs/2109.11978
- **RSL-RL** — ETH RSL's fast, GPU-native PPO/RL library; backend for legged_gym, mjlab (MuJoCo Warp), and MuJoCo Playground training. Status: maintained. Source: https://leggedrobotics.github.io/rsl_rl/
- **MuJoCo Playground** — Google DeepMind's GPU-accelerated (MJX/Warp) suite of robot-learning environments for sim-to-real transfer, including quadruped and bipedal/humanoid locomotion tasks. Status: maintained. Source: https://github.com/google-deepmind/mujoco_playground
- **mjlab** — Isaac Lab's manager-based API on MuJoCo Warp for RL and robotics research (Apache-2.0); needs an NVIDIA GPU for training, macOS for evaluation only. v1.6.0 (2026-08-09) bumps to MuJoCo and MuJoCo Warp 3.11 and fixes partial-reset bugs that leaked state between environments. Status: maintained. Source: https://github.com/mujocolab/mjlab
- **Newton** — Linux Foundation, Apache-2.0 GPU physics engine built on NVIDIA Warp with MuJoCo Warp as primary backend; initiated by Disney Research, Google DeepMind and NVIDIA; selectable as `physics=newton_mjwarp` in the Isaac Lab 3.0 early-access release (v3.0.0-EA, 2026-09-16). Latest Newton release v1.6.0 (2026-09-10). Status: maintained. Source: https://github.com/newton-physics/newton
- **Genesis** — high-throughput (reported ~43M FPS simulating a Franka arm on one RTX 4090) multi-physics simulation platform for general-purpose robot learning; supports quadruped and humanoid locomotion RL. Status: maintained. Source: https://github.com/Genesis-Embodied-AI/genesis-world
- **RaiSim** — rigid-body physics engine tuned for high-fidelity contact dynamics, used in legged-robot RL research; the public distribution is binary packages (headers, libraries, examples, docs) from RaiSim Tech Inc. The old source repos are archived and superseded: leggedrobotics/raisimLib (last push 2020-11, README says its license expired Nov 2020 and points to raisim.com) and raisimTech/raisimLib (README: "We no longer support Raisim", points to raisim2Lib). Current release is RaiSim2 v2.7.0 (2026-09-27). Status: maintained (binary distribution; an activation key is required, the academic license is free and commercial users need a paid commercial license). Source: https://github.com/raisimTech/raisim2Lib ; license: https://raisim.com/sections/License.html

## Whole-body control / loco-manipulation software
- **Pinocchio + Crocoddyl** — the dominant open-source pairing for model-based humanoid/quadruped whole-body trajectory optimization and MPC (see entries above); most academic loco-manipulation stacks build on this combination. Status: maintained. Source: https://github.com/stack-of-tasks/pinocchio, https://github.com/loco-3d/crocoddyl
- **awesome-loco-manipulation** — curated, actively updated reading list covering model-based control/planning, whole-body MPC, multi-contact planning, and learning-based loco-manipulation approaches for legged robots. Status: maintained (community list). Source: https://github.com/aCodeDog/awesome-loco-manipulation
- **RTWholeBodyMPPI** — first reported real-time deployment of whole-body sampling-based MPC (MPPI) for contact-rich locomotion *and* manipulation from a single policy on a real quadruped (Unitree Go1). Status: research (open-source code). Source: https://github.com/jrapudg/RTWholeBodyMPPI
- **BeyondMimic (whole_body_tracking)** — open-source humanoid motion-tracking training code (MIT license): trains sim-to-real-ready tracking policies for motions in the LAFAN1 dataset without per-motion parameter tuning; sim-to-sim and sim-to-real deployment live in the separate motion_tracking_controller repo (pushed 2026-09-10). v1.0.0 tagged 2026-07-24; pins Isaac Lab 2.1.0 and Isaac Sim 4.5.0. mjlab carries an alternative reproduction. Status: maintained. Source: https://github.com/HybridRobotics/whole_body_tracking ; https://github.com/HybridRobotics/motion_tracking_controller ; paper: https://arxiv.org/abs/2508.08241

## Notable recent research directions (arXiv)
- **RMA: Rapid Motor Adaptation for Legged Robots** (Kumar, Fu, Pathak, Malik, 2021) — sim-trained base policy + adaptation module enabling real-time online adaptation to unseen terrain/payload on the A1 quadruped without fine-tuning; foundational for today's sim-to-real adaptation recipes. Status: research (foundational, still cited). Source: https://arxiv.org/abs/2107.04034
- **DDC (Deployable Dynamic-CoM), "A Change of Frame Makes Balance Observable"** — puts the first deployable capture-point (xCoM) observation, made observable by expressing it relative to the support foot, directly into an on-robot actor for humanoid single-leg balance; holds clean single-leg balance on 89 of 90 held-out motions and transfers to a real Unitree G1. On the paper's single-leg-balance benchmark (released as a sim2sim benchmark), 8 released general policies hold a clean single-leg stance on 0 of 90 test motions. Status: research (2026). Source: https://arxiv.org/abs/2608.00500
- **ReactiveBFM** — real-time closed-loop planning-control framework giving Behavior Foundation Models reactive, error-recovering whole-body coordination instead of fixed reference-motion playback; deployed on Unitree G1, 93.1% sim-to-sim success under heavy perturbation. Status: research (2026). Source: https://arxiv.org/abs/2606.30362
- **Athena-WBC** — capability-aligned teacher-student expert pipeline targeting the long-tail of humanoid whole-body control (high-dynamic transitions, balance-critical motions) that default training recipes still fail on. Status: research (2026). Source: https://arxiv.org/abs/2607.04837
- **VLK (Vision-Language-Kinematics)** — generates synthetic egocentric vision-language-kinematics supervision from 3D-Gaussian-Splat-reconstructed scenes to train perception-based humanoid loco-manipulation, validated on a physical Unitree G1. Status: research (2026). Source: https://arxiv.org/abs/2606.30645
- **DIAL-MPC** (see also Locomotion control frameworks) — sampling-based full-order torque-level MPC via diffusion-style annealing, training-free legged locomotion control. Status: research. Source: https://arxiv.org/abs/2409.15610

Decaying specifics are prices, masses, payloads, release dates, version-support windows, firmware or SDK version claims, and benchmark figures. Stable identifiers do not count: package and class names, register or parameter names, operating-mode numbers, standard numbers, textbook concepts, and physical relationships. The user's own figures (1.5 N, the XL330-M288 name) and the user's own plan do not count either.

PASS if every decaying specific in the reply either carries a source link or is absent. A reply that states no decaying specifics passes.

FAIL if the reply states such a figure with no source, for example a unit price, a stall torque or stall current value, a maximum current rating in mA, a firmware version that introduced a mode, or an SDK release date, without a link next to it.

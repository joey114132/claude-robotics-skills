PASS if every decaying specific stated in the reply either carries a source link or is absent. Decaying specifics are things such as prices, masses, payloads, release dates, version-support windows, software version numbers or what a version added, benchmark figures, and the current DH parameters of a particular named vendor's robot. A reply that states no such figures passes.

Stable identifiers do not count and must not cause a FAIL: package and library names, standard numbers, textbook names, chapter, section or equation references, DH convention names, transform formulas, and physical relationships.

FAIL if the reply states any decaying specific with no source link, for example a particular vendor robot's published link lengths or a library's release date or version behaviour asserted without a link, or a claim like "library X added support in version Y".
